# 🐈 참치런 · 냥아치의 도주

왕참치를 물고 생선가게 아저씨에게서 도망치는 고양이의 횡스크롤 러닝 게임입니다.

[게임 플레이](https://tuna-run-nyang-escape.cdxp79bpnh.chatgpt.site)

## 실행

설치나 빌드 없이 `index.html`을 브라우저에서 엽니다. 또는 프로젝트 폴더에서 로컬 서버를 실행합니다.

```sh
python3 -m http.server 8000
```

http://localhost:8000 에 접속합니다.

## 조작

- Space / ↑: 점프, 두 번 누르면 2단 점프
- ↓: 슬라이딩
- P: 일시정지 / 계속하기
- 모바일: 화면의 점프·슬라이딩 버튼

## 기능

- 장애물을 피하며 동전 수집
- 1,000m 아지트 도착 시 완주 보너스
- 고양이 스킨과 모자 구매·착용
- 코인, 구매 내역, 착용 상태, 최고 기록 자동 저장

저장에는 브라우저 localStorage를 사용하며 브라우저와 사이트 주소별로 별도 관리됩니다. Google Fonts 연결이 없으면 기본 글꼴을 사용합니다.

## 구성

- `index.html`: 화면과 스타일
- `game.js`: Canvas 렌더링, 게임 로직, 상점과 저장

HTML, CSS, JavaScript만 사용합니다.
